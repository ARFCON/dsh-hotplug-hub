# 版本号管理规范

## 总则

**版本号只能由仓库 Owner（ARFCON）修改，其他成员一律不得修改。**

## 版本号所在位置

- `package.json` 的 `version`
- `release/DSH-Hotplug-Hub.exe` 的版本信息
- `README.md` 中的版本描述
- 发布 tag：`v0.1.0`、`v0.2.0`

## 规则

1. 只有 Owner 可以修改版本号。
2. 其他成员如需升版本，必须：
   - 在 Issue 中提出申请
   - 说明改动内容和影响
   - 由 Owner 确认后统一修改
3. 任何 PR 中如果包含版本号修改，Owner 有权打回。
4. 版本号格式：语义化版本 `主版本.次版本.修订号`
   - `0.1.0`：初版
   - `0.2.0`：新功能
   - `0.2.1`：修复
