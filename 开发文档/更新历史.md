- 【P0·执行器语义分裂（PC5）】RunCli（超时树杀+只读 stdout+异常→null）与 RunCliLong（超时只 Kill 直接子进程——cmd /c npm 链孙进程孤儿+合并 stderr+异常→ex.Message）同文件两套契约。根治：新建 ProcessContract.RunProcess 单一执行器（超时一律杀树、stderr 合并显式选项、启动失败统一 null「命令不存在」语义、管道 3s 排空），两个旧执行器变薄委托；12 处 RunCliLong 调用方 null 安全逐一核对。
- 【P0·explorer 重启后应用消失（PC6）】无 TaskbarCreated 处理：托盘图标永久消失而 _trayReady 恒 true → 关闭=藏托盘 → 窗口/托盘/任务栏三处皆无、程序驻留只能任务管理器收场。根治：注册 TaskbarCreated 广播 → RebuildTrayIcon（完整重建流程复用 SetupTray）；重建失败降级 _trayReady=false（此后关闭=真退出）；DisposeTrayIcon 完整释放 NotifyIcon+ContextMenuStrip（此前菜单不级联释放）；退出流程（_allowExit）后不再重建。
