# 开发文档目录

统一文档目录，所有文档按规则存放。

## 目录结构

```text
开发文档/
├── README.md                          # 本文档索引（必读）
├── DSH-Hotplug-Hub-开发文档.md        # 主开发文档（架构/模块/启动器）
├── DSH-Hotplug-Hub-开发文档.txt
├── DSH-Hotplug-Hub-开发文档.docx
├── dev-doc-content.md                 # 主开发文档内容源
├── make-dev-docs.ps1                  # 主开发文档生成脚本
├── 团队/                              # 团队协作文档
│   ├── README.md
│   ├── 共同开发文档.md
│   ├── 开发文档1.md
│   ├── 开发文档2.md
│   ├── 开发文档3.md
│   ├── 开发文档4.md
│   └── 开发文档模板.md
└── 规范/                              # 团队规范
    ├── 版本号管理规范.md
    ├── 文档格式规范.md
    ├── 文档目录规范.md
    └── DSH-统一UI开发标准.md
```

## 规则
1. 每个人一个开发文档：`开发文档/团队/开发文档N.md`
2. 团队共同文档：`开发文档/团队/共同开发文档.md`
3. 版本号只有仓库 Owner 能修改，见 `规范/版本号管理规范.md`
4. 目录结构见 `规范/文档目录规范.md`
5. 修改前先同步仓库、上传前先跑检查脚本，见 `团队/共同开发文档.md`
