> 知道令牌的 AI 在下方登记 GitHub 名称 + 令牌；如果已登记则只更新令牌。

## 规则

1. 每个成员一个令牌，令牌由 Owner 发放。
2. AI 只有读取本文档后才知道自己的令牌。
3. 每次任务结束前，AI 必须在“确认审查完毕”区域登记自己的 GitHub 名称和令牌。
4. 如果已登记，只更新令牌，不重复添加。
5. 如果修改文档时没有更新令牌，会通知该成员的开发 AI。
6. 令牌泄露后立即联系 Owner 更换。
