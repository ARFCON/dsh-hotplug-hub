# 任务审查（AI 自动检查）

> 每轮任务结束后，AI 自动执行任务审查，不再询问用户。

## 规则

1. 每轮任务结束，AI 必须自动执行任务审查。
2. AI 自动检查：
   - 修改内容是否符合 `AI_AGENTS.md` 流程
   - 是否已同步仓库、更新 README 公告、写全局记忆
   - 上传前 `check-before-upload.ps1` 是否通过
3. AI 自动登记审查记录。
4. 不需要签名、不需要令牌、不需要登记 GitHub 名称。
