# 任务审查（每轮 AI 自动询问）

> 每轮任务结束后，AI 自动询问是否执行任务审查。

## 规则

1. 每轮任务结束，AI 必须自动询问：
   > 是否执行本轮任务审查？
2. 用户/负责人确认后，AI 登记审查记录。
3. 如果用户选择不审查，AI 记录“跳过审查”即可。
4. 不需要签名、不需要令牌、不需要登记 GitHub 名称。
