## 任务背景

DSH-Hotplug-Hub 已有桌面安装程序 `installer/Setup.exe`，但存在核心短板：

- 安装器默认安装到 `C:\DSH-Hotplug-Hub`，不写注册表卸载项。
- 用户无法从“设置/控制面板”正常卸载，缺少完整卸载程序。

因此本任务为 DSH-Hotplug-Hub 制作一套完整、可靠、有交互式保留选项的卸载程序。

## 实现目标

1. 提供 GUI 卸载确认弹窗：卸载模式 + 可选保留项 + 二次确认。
2. 支持静默卸载 `/S` 与命令行保留/模式参数，适配批量部署和后续安装器集成。
3. 完整清理范围：
   - 运行中的 `DSH-Hotplug-Hub.exe` 进程（优雅关闭 + 超时强制）。
   - 桌面/开始菜单快捷方式（当前用户 + 公共用户）。
   - 安装目录。
   - 用户数据：`%LOCALAPPDATA%\DSH-Hotplug-Hub`、`%TEMP%\dsh-hotplug-hub-webview2`。
   - DSH 共享数据：`%USERPROFILE%\.dsh\hotplug-store`、`%USERPROFILE%\.dsh\hotplug-hub`。
   - 注册表残留：`HKCU\Software\DSH-Hotplug-Hub`、HKCU 卸载键。
4. 不触碰 DSH 官方 Harness 数据（`~/.dsh/profiles`、`settings.yaml`、`.credentials.yaml`）。
5. 卸载过程写 `Log.log`，便于排障。
6. 支持一键重建（`uninstaller/build-uninstaller.ps1`），保证可复现产物。

## 技术路线

采用“复用 DSH Desktop 卸载器成熟模式，针对 Hotplug Hub 精简重构”的路线。

### 经验复用（来自 DSH_Desktop_Uninstaller 项目）
- P2 优雅关进程：`CloseMainWindow` 优先 → 等待 3 秒 → 二次强制 → sleep 500ms。
- P7 安全目录删除：重解析点保护（只删链接本身）、清只读属性、文件优先逐个删、
  子目录递归、最终目录删除不吞异常（配合外层 8 次重试 × 800ms）。
- fake-success 修复：删除失败必须向上抛，不能误报“Deleted directory”。
- 二次确认弹窗：卸载前 MessageBox OKCancel + Warning 展示保留摘要。
- GUI 表单：Microsoft YaHei UI，主题色 `Color.FromArgb(14,124,107)` 与安装器一致。
- 日志：`InitializeLog` + `Log` 追加 `Log.log`（UTF-8）。

### 针对 Hotplug Hub 的差异化设计
- 安装器不写注册表 → 安装目录检测改为多路探测：
  当前 exe 目录、常见安装路径、运行中进程目录。
- 保留项精简为三类：应用配置与数据、DSH 共享缓存、临时缓存。
- 共享数据单独成项，避免卸载误伤 DSH 生态其他组件。
- 构建脚本自动补 UTF-8 BOM，确保 csc.exe 正确编译中文字符串。

### 编译链路
- `csc.exe`（.NET Framework v4.0.30319 / 4.8）→ `/target:winexe` → GUI 子系统。
- 引用 `System.Windows.Forms.dll`、`System.Drawing.dll`。
- `embed-icon-in-exe.ps1` 用 Win32 UpdateResource 把 `release\src\app.ico` 嵌入 EXE。

## 期望实现效果

1. 交互卸载：
   - 双击 `Uninstall_Hotplug_Hub.exe` → 弹窗：
     - 卸载模式：程序识别卸载 / 默认卸载
     - 可选保留项：应用配置与数据 / DSH 共享缓存 / 临时缓存（默认不保留）
     - 点击“卸载”后 → 二次确认（展示将保留哪些内容）→ 开始卸载。
   - 卸载完成后弹窗提示，详细过程记录于当前目录 `Log.log`。
2. 静默卸载：
   - `Uninstall_Hotplug_Hub.exe /S` —— 全删不弹窗。
   - `/S /KeepAppData` —— 保留 `%LOCALAPPDATA%\DSH-Hotplug-Hub`。
   - `/S /KeepSharedData` —— 保留 `.dsh\hotplug-store` + `.dsh\hotplug-hub`。
   - `/S /KeepTempData` —— 保留 `%TEMP%\dsh-hotplug-hub-webview2`。
   - `/S /KeepAll` —— 保留以上全部。
   - `/S /DetectRunning` / `/S /Default` —— 切换安装目录检测模式。
3. 安全性：不会删除官方 Harness 的 profiles/settings/credentials；删除失败不误报成功。
4. 可复现：构建脚本输出固定产物，便于后续接入 CI 或安装器。

### 背景与目标

原「插件包市场」页签（DSH 设置页 + 桌面 WebView2 原型）展示的是内置 6 个假包示例目录（`pack-research` 等），无法获取真实插件。本次将其升级为真实 GitHub 插件市场：

- **介绍与安装方法**：对比抓取 `package.json` / `hotpack.json` / `.dshpack.json` / `README`（README.zh.md 优先）候选文件，提取项目介绍（intro）与「安装」章节（install）；
- **搜索 / 筛选**：关键词搜索、标签多选筛选、来源切换（自动/官方/镜像）、分页加载、本地缓存；
- **一键导入**：为每个条目生成 hotpack manifest，复用既有导入链路（`api.importPack` / `importPacks`）。

### 技术要点

**host 端（lib/index.js）——`marketList(params)`**
- 参数：`{ topic, q, source('auto'|'github'|'mirror'), page, refresh }`。
- 搜索：`GET https://api.github.com/search/repositories?q=topic:<topic>+<q>&sort=stars&order=desc&per_page=10&page=N`；失败按 `GITHUB_MIRRORS`（`ghfast.top` / `gh-proxy.com` / `ghproxy.net`）前缀代理兜底。
- 文件抓取：`raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>`，官方 404 即停不再试镜像；README 候选 `['README.zh.md','README.md','readme.md','README_CN.md','README_ZH.md','Readme.md','README.txt']`（zh 优先）；包清单候选 `['hotpack.json','.dshpack.json','dshpack.json']`。
- 网络兜底：`httpGet` 三层——①运行时全局 `fetch` ②`node:https` 直连（`rejectUnauthorized:false`，仅限公开只读元数据，不触发写操作）③`curl.exe --ssl-no-revoke`。
- 内容提取：`extractIntro`（去 H1→分段→去 HTML/markdown→跳过导航/语言切换行→首非空段，截 280）；`extractInstall`（匹配 `安装|安装方法|安装与使用|Installation|Quick Start|快速开始|使用|Usage|Getting Started` 章节，去 ``` 截 1200）。
- manifest 生成：有 `hotpack.json`/`.dshpack.json` → `parseHotpack` 校验直接入；否则单插件包 `{hotpack:'1.0', id:'pack.<owner>-<repo>', plugins:[{id:'main', source:{type:'github', repo, ref}}]}`。
- 缓存：`~/.dsh/hotplug-hub/market-cache.json`（带时间戳，离线回退并提示）；并发 `MARKET_DETAIL_CONCURRENCY=4`；条目按 stars 降序。
- 红线：不执行包内脚本、白名单正则校验、原子写、仅抓公开只读元数据。

**client 端（lib/client.js）**
- 新增状态：`marketData / marketLoading / marketAppending / marketError / marketSource('auto') / marketTopic('dsh-plugin') / marketPage`。
- `loadMarket`：仅 `!refresh && page===1` 命中缓存；`marketAppending=page>1` 时「加载更多」保留已有卡片、仅底部追加，`loadedRepos` Set 按 repo 去重只抓新条目。
- 多选标签：`marketFilters=[]`，`matchFilters(tags)` 空数组=全部、任一命中；chips 可展开/折叠、点击 toggle。
- 导入：有 `entry.manifest` 用 `JSON.stringify` → `api.importPack`；否则禁用并提示原因。
- Remote 三处同步：`index.js` methods 列表 + `typert.js` invocations + `client.js` REMOTE.descriptors 均含 `marketList`。

**prototype.html（桌面 WebView2 原型）**
- 独立静态页、无 host RPC，浏览器内自 `fetch`（GitHub API + 镜像 + raw，含 CORS 处理），逻辑与 host 端同构（`apiSearchUrls/rawFileUrls/fetchRepoDetail/extractIntro/extractInstall/packIdOf` 等）。
- 修复「加载更多」：`marketAppending` 分支避免整页 spinner 替换已载卡片；`loadedRepos` Set 分页去重。
- 多选标签：`marketFilters` 数组 + `matchFilters`；标签区折叠默认只显 `全部`，展开后多选。
