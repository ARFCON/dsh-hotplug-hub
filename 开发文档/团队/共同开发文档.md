## 修改前必做：先同步仓库

每次修改前必须先把远程仓库同步到工作文件夹：

```powershell
pwsh -File scripts/sync-repo.ps1
```

如果远程有更新，会自动下载到本地。

## 修改前必做：检查是否最近被修改过


**任何人在修改任何代码/文档前，必须先检查目标文件最近是否被修改过。**

### 检查命令

```bash
# 查看该文件最近 10 次提交
git log --oneline -10 -- <文件路径>

# 查看该文件每一行最近是谁改的
git blame <文件路径>

# 查看工作区是否有未提交修改
git status --short
```

### 判断规则

- 如果目标文件**最近 3 次提交内被其他人改过** → 先找对方沟通，再改。
- 如果目标文件**有未提交修改** → 不要直接覆盖，先确认。
- 如果目标文件**很久没动** → 可以正常修改，但改完要在自己的开发文档里记录。

### 检查结果必须记录

每次修改后，在**共同开发文档**和**自己的开发文档**里追加一行：

```text
[2026-08-19] 修改了 xxx，检查 git log 最近修改人：ARFCON / 其他人，无冲突。
```
