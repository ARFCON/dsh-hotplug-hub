## 2. 逐文件改动详情

### 2.1 `dsh-hotplug-hub/dsh-pack-hub/prototype.html`（Web GUI，令牌源）

**改动：把散落字面量抽象为 `:root` 设计令牌，业务类一律 `var(--x)` 引用。**

新增令牌（与《DSH-统一UI开发标准》§2 逐值一致）：

- 色板：`--teal-hover #0a6a5c`、`--sidebar-ink #e7f0ec`、`--nav-ink #d9e7e0`、`--surface-dark #10241f`、`--surface-dark-ink #cde8dd`、`--green-soft #e7f5eb`、`--neutral-soft #f0f2ec`
- 字体：`--font-sans`（界面字体栈）、`--font-mono`（等宽字体栈）
- 圆角：`--rad-sm 6px`、`--rad 8px`（默认）、`--rad-lg 10px`、`--rad-full 20px`
- 阴影：`--shadow-toast 0 8px 24px rgba(0,0,0,.2)`

替换示例：

- `body` 字体字面量栈 → `var(--font-sans)`；`.sidebar` 文字 `#e7f0ec` → `var(--sidebar-ink)`
- 全部 `border-radius:8px` → `var(--rad)`；pill/chip `border-radius:20px` → `var(--rad-full)`；`.badge` 等 10px → `var(--rad-lg)`；`.plugin-row` 6px → `var(--rad-sm)`
- `.btn.primary:hover` 背景 `#0a6a5c` → `var(--teal-hover)`
- `.log-box` 深色底 `#10241f`/文字 `#cde8dd`/等宽字体栈 → `var(--surface-dark)`/`var(--surface-dark-ink)`/`var(--font-mono)`
- `.toast` 阴影 → `var(--shadow-toast)`；`.badge.ok/.neutral` 浅底 → `var(--green-soft)`/`var(--neutral-soft)`
- 模板字符串里内存卡图标角标 `#0e7c6b` → `var(--teal)`

行为无变化，仅样式来源统一。

### 2.2 `installer/Setup.cs`（安装向导）

- 移除文件头 BOM（`\uFEFF`）。
- 新增内部静态类 `Palette`（令牌与 prototype.html :root 同值）：
  - `Teal / TealHover / Ink / Panel` 四个 Color 令牌 + `UiFont / TitleFont` 两个字体
- 窗体与控件改用令牌：
  - 窗體 `BackColor=Palette.Panel`（--panel）、`ForeColor=Palette.Ink`（--ink）
  - 标题色 `Color.FromArgb(14,124,107)` → `Palette.Teal`（--teal）
  - 安装主按钮背景 → `Palette.Teal`，白字，保持 `FlatStyle.Flat`（与 `.btn.primary` 语义一致）

### 2.3 `release/src/Main.cs`（桌面 EXE 壳）——改动最大

**A. 新增内部静态类 `DshTheme`**（17 个成员，令牌与 prototype.html :root 同值）：
`Teal / TealDark / TealSoft / TealHover / Bg / Panel / Ink / Muted / Line / SidebarInk / Green / Amber / Red / SurfaceDark` + `UiFont`。

**B. 消除启动白闪**：`webView.DefaultBackgroundColor = Color.White` → `DshTheme.Bg`（与 Web `--bg` 一致）。

**C. 注入侧栏启动按钮样式改为引用页面令牌**（因与 prototype.html 同页面，直接 `var(--x)`）：
- `border-radius:8px` → `var(--rad)`
- `background:#0e7c6b` → `var(--teal)`；hover `#0a6a5c` → `var(--teal-hover)`
- secondary 文字 `#e7f0ec` → `var(--sidebar-ink)`

**D. API 配置对话框统一 DshTheme**：
- 字体 `new Font("Microsoft YaHei UI",9F)` → `DshTheme.UiFont`；窗体背景/前景 → `DshTheme.Panel / Ink`
- 信息文字 `#17201d` → `DshTheme.Ink`（--ink）
- 「启动官方 DSH 配置」按钮 → `DshTheme.Teal` 底 + 白字 + `FlatStyle.Flat`（与 `.btn.primary` 一致）

### 2.4 `launcher/index.js`（CLI）

- 仅新增头注释：文本输出遵循《DSH-统一UI开发标准》§4.4（状态行大写动词徽标 `ASSEMBLE OK / CHECK OK / HEAL OK / LAUNCH OK`；失败走 `console.error`；详情两级缩进；不引入 ANSI）。
- **零逻辑改动**，行为与命令集不变。

### 2.5 新增 `开发文档/DSH-统一UI开发标准.md`（v1.0.0）

全项目统一 UI 规范的权威文档，覆盖全部 UI 面：Web GUI / 桌面 EXE 壳 / 安装向导 / CLI 文本。要点：

- **原则**：单一事实来源——`prototype.html :root` 是唯一权威色表，C# / CLI 只能映射这组令牌，禁止发明新色值
- **§2 设计令牌**：14 个色板令牌 + 2 字体栈 + 4 圆角 + 阴影 + 动效，含 C# Color 对照值
- **§3 组件规范**：基础控件/状态元素/容器/交互围栏/布局的 DOM+样式约定
- **§4 跨面一致性落地规则**：各 UI 面如何引用令牌与文本风格协议
- **§5 修改与验证流程** + **§7 验收清单**
